WordPressでPHP・サイト設定の確認と安全な診断情報の取得を行うため、Phase 1の管理画面、読み取り専用診断、非公開JSONLログ、権限・nonce付きZIP出力、設定復元・セーフモードを追加します。バージョンは1.0.0-devです。攻撃遮断、改ざん監視、Cloudflare、決済、ライセンス、自動更新は未実装として明示します。

ログはメタデータ許可リストと出力時の再検査を使い、1時間8 MiB・総量500 MiB・ZIP内容16 MiBに制限します。保持対象は168時間ですが、期限超過データの削除は書き込み・Cron実行時です。ダウンロード中のZIPは15分間容量整理から保護し、完了後に削除します。既存PHPエラーハンドラーは維持します。

ローカルのPHP 8.3.6 / WordPress 7.1.4 / MariaDB 10.11.14で単体テスト、実WordPress統合、HTTP管理画面・ZIP、不正nonce拒否、静的解析、WPCS、依存監査、配布テストを実施しました。監査後の正確な件数・修正内容・実行結果は `docs/verification.md` を参照してください。
