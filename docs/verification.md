| 発見事項 | 修正・検証 |

## 1.0.0-dev.1 再監査

2026年11月3日、公開済み`v1.0.0-dev`（`29f5aa8fcbf82428192a62f95ccfafd168019619`）から再点検しました。旧タグ・添付ファイルを上書きせず、修正版を`v1.0.0-dev.1`のPre-releaseとして配布する対象です。

### 発見事項と修正

| 発見事項 | 条件・影響 | 修正 |
| --- | --- | --- |
| 期限切れファイルがZIP出力を妨げる | 古いZIP等が容量を占め、Cron・通常ログが動かないと出力失敗が継続 | 同じ排他ロック内で期限切れを整理してから容量予約を計算。現期間のログを保持 |
| バッファー内の先行出力がZIPへ混入 | headers_sentだけでは未送信のHTML・警告等を検出できず、宣言長と実体が不一致 | 認可後・生成前に除去可能なバッファーと圧縮処理を破棄。除去できないものはZIP送信前に拒否 |
| 終了処理の出力がZIPへ追加される | 他処理のshutdown出力がバイナリー応答を汚す | 当該ダウンロード要求だけWordPressの出力フラッシュを外し、8KiB単位の破棄バッファーで通常の後続出力を抑止。ほかの終了処理は維持 |
| 配布生成が出力先symlinkを辿る | ローカルの不正な出力先で別ファイルを上書きする可能性 | 親ディレクトリも含めてsymlinkを拒否し、専用の一時領域から個別ファイルを置換 |
| ZIP名のOS差と検証途中の出力不整合 | Windowsの区切り・予約名・衝突、ソース側検査失敗後に古いマニフェストが残る | 両OSで安全な名前を生成前に検査。両ZIPとマニフェストを一時領域で完成させ、検証失敗時は従来の出力を保持 |
| 開発更新版のメタデータ | 以前の版検証がdev.1を受け付けない | dev.Nを1〜999に制限して許可し、ログ・ZIP・ビルド・配布の版を整合 |

上記は再現できた不具合・ビルドの安全性の改善です。未認証の遠隔侵入、情報漏洩の発生、CVE登録を確認したという主張ではありません。出力先の最終置換はファイルごとの処理で、OS・ディスクの異常終了まで一括トランザクションを保証しません。公開前のハッシュ照合で不整合を拒否します。

### 公開時の検証

開発版のヘッダーから版と新タグを決定し、StableとRCはこの配布経路で許可しません。テスト済みコミットと配布対象の全バイトを照合します。ReleaseはまずDraftで作成し、4添付ファイルのサイズとSHA-256を検証してからPre-releaseとして公開します。既存タグ・Releaseは置換しません。公開後もダウンロードしてZIPの各ファイル・ハッシュ・版・コミットを検証します。

バッファー外のSAPI直接書込み、意図的に応答制御を変更する別プラグイン、プロセスの強制終了は保証対象外です。WAF・外部連携・販売機能は後続Phaseのままで、正式販売・Stable公開は行いません。
